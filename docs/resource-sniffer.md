# 资源嗅探（Windows）

在 ProxyPin 中启动抓包，再打开“工具箱 → 资源嗅探”。资源在响应头到达时自动入表，因此长视频和直播响应无需结束就能被发现。HTTPS 资源使用 ProxyPin 现有的证书信任和解密能力。

默认识别音频、视频、HLS（M3U/M3U8）和 DASH（MPD）清单。在“识别设置”中可以启用图片识别，或添加扩展名、MIME、URL 正则规则。规则按顺序首次命中，未命中时使用内置识别；正则必须有效才能保存。

扩展名规则可填写 `mp4,webm`，也可以带前导点；MIME 规则支持 `video/*` 等通配写法。这两类规则忽略大小写。URL 正则使用 Dart 正则语法，匹配包含查询参数的完整 URL，并区分大小写。每条规则可单独启用、指定分类和调整顺序；图片分类仍受“识别图片”开关控制。

列表支持分类、域名、关键词筛选与分页。选择资源后可以批量复制链接，或导出 TXT 链接清单、JSON 元信息清单。未选择资源时，对当前筛选结果执行批量操作。资源详情包含完整 URL、状态码、来源信息和识别依据。

窗口默认尺寸为 1280 × 800，并根据当前显示器的可用区域缩小。表头保持固定，列表各列随窗口宽度调整，不需要左右滚动；长内容可悬停查看或打开详情。列表右侧提供常驻、可拖动的纵向滚动条，可使用滚轮、拖动滚动条或点击轨道查看本页的其余资源。

点击列表中的“预览”图标，可以加载视频首帧，并在列表中查看分辨率与时长。打开资源详情可以查看更大的画面，以及能取得的编码、帧率、码率和格式信息。图片可以显示缩略图及原始分辨率，音频可以显示能取得的时长和编码。

预览仅在点击后访问资源 URL，沿用捕获请求所需的 Referer 等请求头；打开窗口、筛选和导出不会请求媒体。只支持重新读取 GET 资源，不重放 POST 请求。预览结果仅在内存中缓存，不随清单导出图片或认证请求头。同 URL 的资源分类、MIME、大小或 ETag / Last-Modified 变化时，会清除旧首帧与预览信息，并取消旧预览；再次点击才加载新内容。关闭窗口会取消该窗口的未完成预览，清空列表会同时取消预览并清理缓存。

视频与音频预览使用成熟的 `media_kit` 组件，由 libmpv/FFmpeg 识别格式、解码首帧并提供媒体信息。Windows 构建固定打包 LGPL 版本的 libmpv 动态库，无需另外安装播放器。每次预览最多读取 16 MB，20 秒超时，图片读取最多 8 MB，清单读取最多 1 MB；超限或无法解码时可重试。HLS/DASH 目前仅解析清单中的分辨率、编码、码率等信息，不加载媒体分片、密钥或首帧，也不自动播放。

预览失败时，详情会区分资源请求、正文读取、清单解析和媒体解码等阶段，显示可取得的 HTTP 状态码。HTTP 失败可能由过期链接或访问限制引起；预览组件加载失败会单独提示。若响应声明为 MP4，但已读取的开头没有可识别的 MP4 文件头，会提示内容可能经过加密、混淆或损坏；仅凭 URL 参数不能确定其加密方式。本版不解密平台专有媒体，无法为这类响应生成首帧。

播放器仅访问临时本地预览桥接服务，真实 URL 与认证头由主窗口处理。媒体、图片与清单请求强制直连，不使用系统或 ProxyPin 代理；播放器也禁用环境变量中的 HTTP 代理，桥接请求不进入资源嗅探列表。禁止播放器打开嵌套媒体引用、外部轨道、字幕或播放清单；解码保持静音暂停状态。第三方组件许可证和固定版本源码链接随 Windows 包一起提供。

关闭嗅探窗口后继续记录；“暂停”停止新增识别并保留列表，“清空”只清理嗅探结果。多个窗口共享暂停状态，保存识别设置不会改变暂停状态。暂停状态和规则保存到应用配置目录的 `resource_sniffer.json`。资源列表最多保留 2,000 条，重启应用后清空；同一完整 URL 聚合出现次数，查询参数不同的链接分别保留。已识别的资源返回 304 时，沿用已有资源分类并更新次数与最近时间；新的成功响应无法取得大小时显示“未知”，不会使用上一请求的大小。

资源下载、媒体播放、切片解析合并、解密、直播录制以及浏览器脚本注入不在本版范围内。

功能设计参考 [Cat Catch 的公开识别说明](https://cat-catch.94cat.com/docs/settings)，使用本项目的 Dart/Flutter 实现并沿用 Apache-2.0 许可证。
